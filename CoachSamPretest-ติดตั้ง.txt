สิ่งที่หน้าเว็บทำ
- มีปุ่มทำ Pre-Test ในหลักสูตรทั้ง 21 รายการ
- แบบทดสอบปรนัย 10 ข้อ แสดงเป็นหน้าต่างใช้งานได้บนมือถือ
- เมื่อตอบครบจะแสดงฟอร์มข้อมูลและข้อความยินยอมก่อนส่ง
- เมื่อ Apps Script ยืนยันการบันทึก จึงแสดงคะแนนและเปอร์เซ็นต์
- ระบบส่งรหัสหลักสูตรไปบันทึกแยกแท็บตามรหัส

ข้อมูลที่บันทึก
เวลา, รหัส/ชื่อหลักสูตร, ชื่อ-สกุล, อีเมล, Line ID, เบอร์โทร,
จังหวัด, การยินยอม, คะแนน, คำตอบ 10 ข้อ, Submission ID และรุ่นข้อความยินยอม

หมายเหตุสำคัญ
- การ Deploy แบบ Anyone ทำให้ endpoint รับข้อมูลจากสาธารณะได้ จึงควรเก็บ Google Sheet เป็นส่วนตัวและแชร์เฉพาะผู้ดูแลที่จำเป็น
- สคริปต์ไม่เก็บ IP address และไม่ส่งข้อมูลส่วนบุคคลกลับไปยังหน้าเว็บ
- คะแนนในรุ่นนี้คำนวณที่หน้าเว็บและส่งพร้อมคำตอบ ผู้ใช้ที่มีความรู้ด้านเทคนิคอาจแก้คะแนนก่อนส่งได้ หากจะใช้เป็นการวัดผลทางการ ควรปรับให้ Apps Script ตรวจเฉลยบนเซิร์ฟเวอร์
- คำถามเป็นชุดประเมินพื้นฐานที่จัดตามหัวข้อหลักสูตร ชุดที่ไม่มีเอกสารหลักสูตรอ้างอิงควรให้ผู้สอนตรวจทานก่อนใช้งานจริง
- หน้าเว็บฉบับแก้ไขถูกบันทึกและ commit ในเครื่องแล้ว แต่การ push ไป GitHub ถูกปฏิเสธเพราะข้อมูลยืนยันตัวตนที่ใช้ไม่มีสิทธิ์เขียน repository นี้
